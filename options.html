Keyboard shortcut

Ctrl+Shift+D (Windows/Linux) or Cmd+Shift+D (Mac) is built into this extension. On regular web pages it takes that combination away from Chrome’s “Bookmark all tabs” command.

Chrome still owns the shortcut on its own pages (New Tab, Settings, the Web Store, and other chrome:// URLs). Assign the same keys below if you want duplication there too.
